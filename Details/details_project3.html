DETAIL PROYEK / 01

Website penyewaan barang inventaris UK - KBMK Polnes

HTML CSS PHP MySQL Database JavaScript Peminjaman

DESKRIPSI PROYEK

Project ini adalah hasil project untuk kebutuhan skripsi sebagai syarat kelulusan dan di project ini berfokus pada website peminjaman barang inventaris yang dibutuhkan untuk keperluan sekre KBMK Polnes. Dengan menerapkan fitur seperti keranjang belanja, dengan bahasa HTML, CSS, dan dibantu database mysql dan PHP.

FITUR UTAMA

  • Manajemen organisasi kampus Politeknik Negeri Samarinda
  • Manajemen penyewaan barang dengan fitur memilih barang bisa satu atau lebih lewat keranjang penyewaan yang dilakukan oleh ogranisasi kampus lain.
  • Menghitung berapa total harga yang dibayar untuk semua barang yang disewa dengan satu barang per hari.
  • Fitur Pembayaran lewat QRIS.
  • Upload berkas surat organisasi setelah melaukan peminajman.
  • Fitur denda jika terlambat mengembalikan barang sesuai batas tanggal pengembalian
  • Laporan data peminjaman barang selama sebulan.

JOB DESK / PERAN

  • Membuat desain rancang bangun website dengan alur flowchart, ERD, DFD, FOD
  • Membuat database dengan relasi yang ada pada desain rancang bangun sebelumnya
  • Melakukan pengembangan lewat codingan website dengan menerapkan bahasa HTML dan CSS serta javascript untuk front end
  • Melakukan back end dengan PHP untuk dihubungkan dengan database agar data bisa ada pada website
  • Melakukan tes uji coba lewat percobaan website apakah ada bug dan error yang masih ada pada website
  • Melakukan hosting untuk di publish agar website bisa digunakan secara universal
  • Melakukan juga pengujian lewat tes black box testing untuk menguji apakah website aman digunakan.

Hasil Project

    Website berhasil digunakan tanpa ada hambatan lewat keranjang peminjaman , konfiormasi pembayaran dan penambahan data barang yang dilakukan oleh admin. Meskipun itu masih ada hal yang kurang lewat desain UI/UX yang masih sederhana. Juga pada hasil skripsi Meskipun sudah selesai revisi masih ada yang perlu ditambahkan fitur dan pengembangan yang masih kurang. Tapi dengan penilaian tersebut maka website masih digunakan oleh pihak sekre UK-KBMK Polnes yang dimana kedepannya dikembangkan lewat UI/UX dan database dan fitur yang masih kurang di website ini.
